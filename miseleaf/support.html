Using the app

Add and edit personal recipes, search or filter the library, mark favorites, and keep cooking progress on this device. You can select a recipe photo through Android's Photo Picker. Miseleaf works without an account or internet connection.

Exporting and importing recipes

In Settings, choose Export backup to save a readable JSON file through Android's document picker. Choose Import backup to select a file, review the new, updated, and unchanged counts, and decide whether to commit it. Matching recipe identifiers update existing recipes; unchanged records are skipped, and a matching recipe's device-local photo is retained.

The JSON file contains recipe content but not photo files or cooking-session progress. Keep it in a location you trust. If you choose a cloud-backed document provider, that provider handles the saved file under its own settings. Miseleaf does not automatically back up or sync your recipes, so an exported JSON file is the available way to move recipe text to another device.

Removing local data

You can delete individual recipes or use Delete all local data in Settings. Delete all clears the recipe database and attempts to remove app-managed photo copies; it does not delete JSON files saved outside the app or reset your appearance choice. Clear app storage in Android or uninstall to remove the remaining app-private data. Delete exported files separately from their chosen location.

Privacy

Read the Privacy Policy for details about local data, photos, export/import, retention, and third-party document providers.
